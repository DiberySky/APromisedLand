Markdown 的核心思想是 **“易写易读”**，日常使用其实只需要掌握 20% 的常用语法就能覆盖 80% 的场景。下面是真正的“常规操作”速查手册：

---

### 1. 标题（层级清晰）
```markdown
# 一级标题（对应 HTML 的 <h1>）
## 二级标题
### 三级标题
###### 六级标题（最小）
```
> **常规操作**：`#` 与标题文字之间保留**一个空格**。

---

### 2. 文字强调（加粗与斜体）
```markdown
*斜体*  或  _斜体_
**加粗** 或  __加粗__
***加粗斜体***
~~删除线~~（划掉内容）
```
> **常规操作**：常用 **加粗** 来突出关键词。

---

### 3. 列表（无序与有序）
**无序列表**（最常用）：
```markdown
- 项目一
- 项目二
  - 子项目（缩进 2 或 4 空格）
```
**有序列表**（带编号）：
```markdown
1. 第一步
2. 第二步
   1. 子步骤（自动缩进）
```
**任务清单**（GitHub/笔记软件常用）：
```markdown
- [x] 已完成的任务
- [ ] 待办事项
```

---

### 4. 链接与图片
```markdown
[显示文字](https://example.com "可选标题")
![图片替代文字](图片URL)
```
> **常规操作**：写技术文档时，常用 `[引用名]: URL` 的方式在文末统一管理链接，让正文更干净。

---

### 5. 代码（日常刚需）
**行内代码**（用于变量、函数名）：
```markdown
这段代码用到了 `Console.WriteLine()` 方法。
```
**代码块**（粘贴大段代码）：
~~~markdown
```csharp
// 指定语言可高亮（如 csharp, python, json, bash）
var result = "Hello World";
Console.WriteLine(result);
```
~~~

---

### 6. 引用（标注别人的话或注释）
```markdown
> 这是一段引用的文字。
> 换行继续引用。
>> 可以嵌套多层引用。
```

---

### 7. 表格（规整数据）
```markdown
| 左对齐（默认） | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 单元格1 | 单元格2 | 单元格3 |
| 内容A | 内容B | 内容C |
```
> **常规操作**：表头下方的分割线 `---` 不能省，对齐方式靠冒号位置决定。

---

### 8. 分割线（视觉分段）
```markdown
---   （三个减号）
***   （三个星号）
```
> 常用在正文前后，制造醒目的分界效果。

---

### 9. 转义字符（显示特殊符号）
如果想让 `*` `#` `-` 等符号直接显示出来，而不是被渲染，在前面加反斜杠 `\`：
```markdown
\# 这不是标题，只是显示一个井号
```

---

### 💡 常规操作“潜规则”

- **换行**：在 Markdown 中直接回车不会换行，需要在上一行末尾加**两个空格**再回车，或者直接空一行（产生新段落）。
- **兼容性**：大多数平台（GitHub、Typora、语雀、Notion）都支持上述语法；如果是写 `README.md`，记得利用 **Emoji**（如 `:smile:`）或 **HTML 标签**（如 `<kbd>Ctrl</kbd>`）让文档更生动。
- **嵌套规则**：列表、引用、代码块可以互相嵌套，只需保持正确的缩进（通常为 2 或 4 个空格）。

---

### ✅ 总结一句话
> 日常只需要会用 **标题 + 加粗 + 列表 + 代码块 + 链接**，就能写出像样的技术文档或笔记了。需要复杂排版时（如流程图、数学公式），再按需查阅对应扩展语法（如 Mermaid、LaTeX）即可。
