既然上轮已经聊过 **Git Bash** 里的 Git 命令，这次就专门聚焦于 **Bash（Shell）本身** 的常规操作——毕竟，Bash 是你在终端里和操作系统对话的“母语”。

抛开 Git 不提，日常开发中高频使用的纯 Bash 操作，可以分为 **文件管理**、**文本处理**、**进程控制** 和 **快捷键神操作** 四大块。

---

### 1. 文件与目录管理（比鼠标快 10 倍）

| 命令 | 作用 | 高频示例 |
| :--- | :--- | :--- |
| `ls -lah` | 查看当前目录所有文件（含隐藏、带大小、人类可读） | 进新项目必敲 |
| `cd -` | **返回上一个目录**（不用傻傻打路径） | `cd -` 瞬间切回 |
| `mkdir -p a/b/c` | 一次性创建多级嵌套目录 | 建项目结构时巨好用 |
| `cp -r src/ dst/` | **递归复制**整个文件夹 | 备份代码 |
| `mv` | 移动或**重命名**（改名神器） | `mv old.txt new.txt` |
| `rm -rf` | **强制递归删除**（极度危险，Linux 版“格式化”） | 删 `node_modules` 或 `.git` |

---

### 2. 文本查看与处理（不打开编辑器看文件）

| 命令 | 作用 | 说明 |
| :--- | :--- | :--- |
| `cat file.txt` | 一次性输出全文 | 适合看小配置文件 |
| `less file.txt` | **分页查看**（按 `q` 退出，按 `/` 搜索） | 看大日志必备 |
| `head -n 20 log.log` | 只看**前 20 行** | 查看最新报错头部 |
| `tail -f log.log` | **实时滚动**查看文件末尾 | 看程序运行时输出的日志（救命技） |
| `wc -l file.txt` | 统计文件**行数** | 看代码量 |
| `grep "error" log.log` | 在文件中搜索关键词（支持正则） | 查找报错 |

---

### 3. 管道与重定向（Bash 的灵魂杀手锏）

Bash 最强大的地方在于 **把命令像积木一样拼起来**：

- **`|`（管道）**：把左边命令的输出，直接丢给右边命令当输入。
  ```bash
  ps aux | grep dotnet   # 找所有 dotnet 进程
  history | grep commit  # 在历史命令中找 commit 记录
  ls -la | wc -l        # 统计当前目录有多少个文件
  ```

- **`>`（覆盖写入）** 和 **`>>`（追加写入）**：把终端显示的内容存到文件里。
  ```bash
  echo "Hello" > test.txt   # 覆盖写入
  echo "World" >> test.txt  # 追加在末尾
  ```

### 4. 进程与后台管理（程序跑挂了怎么办）

| 操作 | 作用 | 场景 |
| :--- | :--- | :--- |
| `ps aux` | 查看所有正在运行的进程 | 找 PID（进程号） |
| `kill -9 PID` | **强制杀死**指定进程号的应用 | 端口被占用，暴力解决 |
| `命令 &` | 在**后台**运行程序（不阻塞终端） | `dotnet run &` |
| `Ctrl + Z` | 暂停当前前台进程，扔到后台挂起 | 忘了加 `&` 时救急 |
| `jobs` | 查看当前终端下的后台任务列表 | 看看挂了几个任务 |
| `fg %1` | 将后台任务号 1 调回前台 | 重新接管控制权 |

---

### 5. 环境变量与别名（偷懒必备）

- **查看环境变量**：`echo $PATH`（看系统找程序的路径）
- **临时设置变量**：`export MY_NAME="dibery"`（只在当前终端有效）
- **设置别名（偷懒大法）**：
  ```bash
  alias ll='ls -lah'          # 以后敲 ll 等于敲 ls -lah
  alias gs='git status'       # 敲 gs 等于 git status
  ```
  （想把别名永久保存，写入 `~/.bashrc` 文件）

---

### 6. 终端快捷键（手指不用离开键盘）

这些能让你瞬间变身终端高手：

| 快捷键 | 作用 | 场景 |
| :--- | :--- | :--- |
| `Ctrl + A` | 光标跳到**行首** | 改长命令的前缀 |
| `Ctrl + E` | 光标跳到**行尾** | 改长命令的后缀 |
| `Ctrl + U` | **删除**光标左边所有内容 | 输错密码或路径 |
| `Ctrl + K` | 删除光标**右边**所有内容 | 清掉后半段命令 |
| `Ctrl + R` | **反向搜索**历史命令（输入关键字） | 找回几个月前敲过的长命令 |
| `!!` | 重复上一条命令 | `sudo !!`（权限不够时补 sudo） |
| `Tab` 键 | 自动补全路径/命令 | 不用背长文件名 |

---

### ✅ 一句话总结
> 日常用得最溜的 Bash 三板斧是：**`ls` 看文件 + `cd` 切路径 + `grep` 搜内容**；高阶一点就记住 **`|` 管道拼接** 和 **`Ctrl+R` 搜历史**。掌握这些，你就已经超越了 90% 的鼠标依赖者。
