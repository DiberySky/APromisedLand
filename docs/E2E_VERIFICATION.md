# 空间功能 E2E 验证清单

## 前置

- [ ] 服务已启动：`dotnet run --project TreeGraph.Api`
- [ ] Blazor 已启动：`dotnet run --project TreeGraph.Blazor`
- [ ] 数据库已迁移：`dotnet ef database update`
- [ ] 记录 API 端口（如 7001），前端端口（如 7000）

## A. 后端 API（curl）

- [ ] 运行 `bash scripts/e2e-space-verify.sh`
- [ ] 全部 ✅
- [ ] 运行 `psql -d treegraphdb -f scripts/e2e-space-verify.sql`，孤立检测三条为空

## B. 桌面端 UI

### B1. 空间列表页 `/spaces`

- [ ] 打开页面 → 显示空间列表 + 右侧树
- [ ] 右上角有 ⚙ 管理入口
- [ ] 点击空间 → 右侧树切换
- [ ] 拖动分隔条 → 左栏宽度变化
- [ ] 刷新页面 → 宽度保持（localStorage）

### B2. 空间管理页 `/spaces/admin`

- [ ] 打开页面 → 表格视图
- [ ] 每行显示「属性集」徽章
- [ ] 新建独立空间 → 徽章显示「独立 · 0 个属性」
- [ ] 新建共享空间 → 徽章显示「共享 · N 个属性」
- [ ] 点击徽章 → 跳元数据页
- [ ] 编辑空间名 → 列表刷新
- [ ] 删除空间 → 二次确认 → 消失

### B3. 空间树页 `/spaces/{id}`

- [ ] 顶部 AppBar 显示空间名
- [ ] 点返回 → 回 `/spaces`
- [ ] 建子节点 → 出现在树下
- [ ] 点节点「属性」→ 弹窗按该空间 Schema 渲染
- [ ] 填品牌/价格 → 保存 → 重新打开值一致

### B4. EAV 元数据页 `/eav/metadata/by-space`

- [ ] 显示四个分组（独立/共享/孤立/其他）
- [ ] 独立空间显示空间名 + "独立空间属性集"
- [ ] 点击「查看属性」→ 跳转（或至少 URL 变化）

## C. 手机端 UI（DevTools iPhone 模式）

### C1. 空间列表页 `/spaces`

- [ ] 全屏列表，无右侧栏
- [ ] AppBar 有 ⚙ 和 +
- [ ] 点卡片 → 跳 `/spaces/{id}`
- [ ] 点 ⚙ → 跳 `/spaces/admin`

### C2. 树视图 `/spaces/{id}`

- [ ] 顶部有返回箭头
- [ ] 点返回 → 回 `/spaces`
- [ ] 节点带「⋯」或内联按钮
- [ ] 点「属性」→ 弹窗正常

### C3. 管理页 `/spaces/admin`

- [ ] 卡片式列表
- [ ] 每张卡片下方显示徽章
- [ ] 点卡片主体 → 进树（不触发徽章）
- [ ] 点徽章 → 跳元数据页

## D. 边界场景

- [ ] 空数据库启动 → `/spaces` 显示空态 + 创建按钮
- [ ] 删除最后一个空间 → 回到空态
- [ ] 删除有子树的独立空间 → 子树 + 属性全清
- [ ] 创建共享空间 → 不生成独立 EntityType
- [ ] 从模板复制 → 新空间属性与模板一致
- [ ] 元数据页孤儿检测 → 手动删空间后无孤儿

## E. 性能

- [ ] 20 个空间 → `/spaces/admin` 首屏 < 1s
- [ ] 100 个节点树 → 展开流畅
- [ ] 属性过滤 → < 2s 返回

## F. 兼容性

- [ ] 老数据（`entity_type` 默认 `StringTreeNode`）→ 行为不变
- [ ] 已有 EAV 元数据页仍可用
- [ ] `TreeKey` 机制不受影响
